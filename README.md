# 🦅 Kayi Stream Bot — Telegram File to Direct Link & Web Player

A fast, low-memory Telegram bot that converts ANY video, audio, or document into an instant direct browser download link and HTML5 streaming web player URL. Part of the **@KayiBots** suite.

---

## 🌟 Key Features
- 🚀 **High-Speed Direct Download Link:** Works with IDM, curl, wget, and web browsers.
- 📺 **Online Video Player:** Stream directly in VLC, MX Player, Smart TV, or in-browser HTML5 player.
- ⚡ **Zero-Disk Streaming:** Streams chunks in 64KB buffers without storing huge media files on disk, staying well within Render's free tier (512MB RAM).
- ⏱️ **HTTP Range Support:** Full video seeking (rewind / fast-forward) in video players.
- 🛡️ **Anti-Abuse Protection:** 5 files/min rate limiting and 24-hour token expiration.
- 📢 **Ecosystem Logging:** Sends generation logs and restart notifications to `@KayiBots` log channel.
